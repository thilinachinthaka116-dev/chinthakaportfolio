THILINA CHINTHAKA — MALTA JOB PORTFOLIO

HOW TO OPEN
1. Extract this ZIP folder.
2. Double-click index.html to open it in a modern browser.
3. Keep index.html, style.css, script.js, the assets folder and Chinthaka_CV.pdf together.

FEATURES
- Responsive desktop, tablet and mobile design
- Light/dark theme switch (remembers selection in browser)
- Animated section reveal and mobile navigation
- CV PDF download links
- Contact links for email and telephone

IMPORTANT
This is a static portfolio website. To publish it online, upload the extracted folder to a static hosting provider. The work dates and details are presented from the supplied CV. Check any Malta driving-licence recognition requirements with the relevant authorities/employer before applying.
